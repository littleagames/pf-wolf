PFWolf for Windows
==================

Unzip this folder anywhere and run PFWolf.exe (the editor is PFWolf.Editor.exe). Nothing needs
installing: the .NET runtime, SDL2 and OpenAL Soft come with it.

The game's data files
---------------------
PFWolf plays the original games' data files, which aren't included. Copy them (VSWAP.WL6,
VGAGRAPH.WL6, AUDIOT.WL6, GAMEMAPS.WL6 and the rest, from Steam, GOG or the shareware) into
this folder, beside PFWolf.exe, or into %LOCALAPPDATA%\PFWolf\.

Where things go
---------------
  Settings, saves, screenshots, recorded demos   %APPDATA%\PFWolf\<game>\
  Mods                                           mods\ in this folder, or %LOCALAPPDATA%\PFWolf\mods\
  The editor's settings                          %APPDATA%\PFWolf\Editor\
  A crash report (crash.log)                     this folder, else %LOCALAPPDATA%\PFWolf\
