## The example mods

The PFWolf repository's [example mods](../../../examples/mods) each show off a feature, and the
[examples README](../../../examples/README.md) walks through what's in each one. They're built
with PFWolf, in the game's `mods` folder, ready to switch on.

| Mod | Shows |
| --- | --- |
| Moody Lights | Shading and lights, all data |
| Switch Demo | Wall switches, tags, light zones and scrolling walls |
| Tall Walls Demo | Walls several stories tall, arches and a sky |
| Patch Demo | Pictures on walls, and patches that are switches |
| Fireball Demo | Traps, projectiles and Lua scripting |
| Faction Demo | Sides that fight each other, followers, color translations |
| Medic Demo | Enemies that revive their fallen |
| Key Demo | More keys, and doors that need two of them, any two, or all four |
| Standalone Demo | A game of its own, with none of Wolfenstein 3D's files |
