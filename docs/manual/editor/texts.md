# Texts

**Resources → Texts…** (F2) lists the texts the game shows as articles: the help screens, the end
texts and the briefings, from the data files, pfwolf.pk3 and the mods. Find one by name or by what
shows it: *helpart*, *cluster 2*, *briefing*.

Picking one shows each page as the game lays it out, at twice its 320×200, beside the text it's
made of. ◀ and ▶ (or Page Up and Page Down) turn the pages, and clicking a word or picture on the
page finds it in the text. As the text is changed the page follows, and what's wrong with it is
listed: an error is something the game would quit showing. Picking one goes to it.

**Shown by** says what in game-info shows the text, and **Where it comes from** where it's read
from, the last being the one the game uses.

**Save** (Ctrl+S) writes `texts/NAME.txt` into the text's mod, where the game reads it in place of
its own; *Save to…* into another mod's texts folder, and *Revert* goes back to it as the game has
it. **New…** (Ctrl+N) starts a text, to save in a mod and name in game-info; *Delete…* takes a
mod's own text out.
