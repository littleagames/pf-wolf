# Feature tour mod — plan

`examples/mods/feature-tour`: a Wolf3D mod with one room per engine feature, built for
recording the Shorts in [showcase.md](showcase.md) and taking documentation screenshots.
Every room is a self-contained set: you can `tp` into it, frame the shot, and record
without anything else in view.

## Goals

- One room = one feature = one Short (room numbers match the showcase list where possible).
- Rooms are reachable by walking (for real play-through footage) **and** by `tp` from the
  console (for fast, repeatable takes).
- Everything generated by a script, like the other examples:
  `examples/tools/make-feature-tour.ps1` draws the textures/patches and writes the maps, so
  layout changes are a re-run, not hand editing.
- Original art only (drawn by the script, like tall-walls-demo and patch-demo), so footage
  can be shown freely. Stock Wolf3D textures are fine for walls.

## Layout

Three maps, because fog, night and weather are per map, not per zone:

| Map | Name | Holds |
|-----|------|-------|
| MAP01 | The Gallery | a central hall with wings of rooms (renderer, lighting, gameplay) |
| MAP02 | Night Courtyard | outdoor night: fog, rain, sky, tall walls, covered colonnade, lamps |
| MAP03 | Winter Keep | daylight snow/blizzard, tall towers, flats, diagonals outdoors |

MAP01 is a hub: a long hall with numbered doors, a sign patch over each door naming the
feature. An elevator at the end goes to MAP02, then MAP03.

### MAP01 — The Gallery

**Renderer wing**
1. **Atrium** (look up/down) — 3-story room with a ceiling flat skylight and banners high
   up, so pitch has something to show. Also the eye-height/death-drop spot (a guard waits
   here, or use `kill`).
2. **Tall walls hall** — 2/3-story walls, arches, a stepped colonnade; tall textures in the
   tall-walls-demo style (redrawn by the new script, not copied from that mod).
3. **Diagonal room** — octagonal room plus a zig-zag 45° corridor (markers 400–403); the
   automap shot comes from here too.
4. **Floors and ceilings** — a checker-tiled floor, wood ceiling, a rug flat in the middle,
   a lattice ceiling with see-through (0xFF) pixels.
5. **Fence garden** — wall-sprite fences and gates, straight and diagonal, a guard behind a
   fence (shoots through) and one behind a gate (can't).
6. **Poster wall** — wall patches: posters, cracks, a button patch that works as a switch,
   a medkit patch that hands out health.
7. **Mirror hall** — a corridor whose walls use `flip:` so asymmetric textures read the
   same on both sides.
8. **Animated room** — animdefs: flickering screens, a flowing lava/water flat, an animated
   sign patch.

**Lighting wing**
9. **Lamp room** — dark room (low zone light) with coloured halo lights: chandelier amber,
   red pulsing lamp, a blue lamp; best spot for muzzle-flash footage.
10. **Light switch room** — a switch fades the room from dark to full (A_SetZoneLight); a
    second triggers a red strobe alarm.
11. **Tint corridor** — three zones in a row: red, blue, green-white; bright-state sprites
    (lamps that ignore the dark).

**Gameplay wing**
12. **Switch room** — switches that open a door, move a wall, spawn an actor.
13. **Pushwall race** — four tagged pushwalls that move at once from one switch.
14. **Faction arena** — guards vs SS fight in a pit, viewed from a balcony behind a fence.
15. **Trap corridor** — Lua fireball walls firing in patterns.
16. **Pickup row** — a line of items for HUD messages (mod's game-info turns messages on).
17. **Class gate** — optional: a restricted item that only one player class can take.

### MAP02 — Night Courtyard

Night shading with blue-black fog, sky, heavy rain with splashes; a covered colonnade
(arches + ceiling flats) where the rain stops; lamp posts with halo lights; tall gate and
towers. One Short on its own ("It's raining in the castle") and the trailer's mood shot.

### MAP03 — Winter Keep

Daylight, blizzard with gusts, white fog; towers, diagonal battlements, snow flats on the
ground, a warm-lit doorway into a hall (snow stops at the roof line).

## Recording kit

- **Stations list** in the mod's README: room number, `tp x y angle`, what to do, which
  Short/doc page it serves. Optionally a `scripts/` Lua console helper (`tour 5` → teleport
  to room 5) if the scripting API allows registering console commands; otherwise the
  `tp` list is enough.
- **Shot checklist**: per room, the frames needed for docs (one wide, one close-up, one
  automap where it applies).
- Clean HUD option for Shorts: note the console commands that hide the status bar / weapon
  (or add them if missing).
- Vertical video: try a 1080×1920 window (Hor+ may make it very narrow) vs recording 16:9
  and cropping; pick one and note it in the README.

## Phases

0. **Engine gaps** (small, separate commits)
   - mapdefs object ids for wall sprites (8 per class, one per facing) — currently
     `summon`-only, so the fence garden can't be placed in a map.
   - Check whatever the clean-HUD and `tp` workflow needs.
1. **Script + MAP01 skeleton** — `make-feature-tour.ps1` writing a 6-plane WAD (walls with
   patch high byte, objects, flats, heights, tags, zones), the hub hall, door signs, the
   renderer wing (rooms 1–8) and their textures/flats/patches/animdefs.
2. **Lighting + gameplay wings** — rooms 9–17: zones in game-info, actordefs lights,
   switches in walls.yaml, factions, the Lua traps, messages on.
3. **Outdoor maps** — MAP02 and MAP03 with per-map shading/sky/weather.
4. **Verify + kit** — play-through of all three maps, headless screenshots of each station,
   README with the stations list, update `examples/README.md` and showcase.md's "Ready demo"
   column. Run the existing tests (content checks on example mods).

## Open questions

- **Map slots**: replace MAP01–03 (like the other demos; clashes with them, so enable one
  at a time) — recommended — or new map names reached only by `--warp`.
- **Copy vs reference** the other demos' content (patch-demo textures, fireball Lua,
  faction defs): recommended to regenerate/copy into the tour so it stands alone.
- **Multiplayer and editor** features stay out of the tour; they have their own maps
  (multiplayer.pk3) and need screen recordings of the editor instead.

## Already untested features this will exercise

Per memory notes: multiple pushwalls in-game, wall-sprite projectiles, arches inside light
zones, weather in fog/night, flats in an actual map, mirrored textures in-game. Expect
phase 4 to turn up a few bugs; fix them before recording.
